- 做法：`combo_same_attack_3` 的 `required_cards` 由 `type:attack;count:3` 改為 `subtype:same;count:3`（描述已寫「同一類別」）。`comboResolver.matchesSameSubtypeCount` 已存在，會走同 subtype 路徑。執行 `npm run build:data` 重新生成 `generated/combos.json`。同步更新依 `type:attack` 觸發的測試預期。

**8b `combo_line_attack`（收緊判定）**
- 檔案：`server/game/rules/comboResolver.js`（`detectBoardPattern` "line"）、`tests/rules/comboResolver.boardPattern.test.js`
- 做法：`line` 判定由「`dx===0 || dy===0`（攻擊者—目標成直線）」改為：計算與目標同列（同 x）或同行（同 y）且未淘汰、非攻擊者的敵方數量，≥2 才回 true（包含目標本身，即目標所在線至少有另一名敵方）。「同時攻擊全部直線上敵人」邏輯（`lineAttackActive`）維持不變。
- 更新測試：既有「單一目標成直線即觸發」的期望（boardPattern.test.js:66-94）改為「僅 1 名直線敵人 → 不觸發」；「2 名直線敵人 → 觸發」（:126-161）維持。
- 驗證：`npm run test:rules`。
