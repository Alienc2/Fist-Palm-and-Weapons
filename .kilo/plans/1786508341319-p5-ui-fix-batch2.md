# P5 UI 修正（第二輪）— 對戰紀錄 / 扇形手牌 / 選牌卡面

## 目標
依用戶三項回報修正：

1. 對戰紀錄仍顯示卡牌 id（例 `shop_adv_weapon_1`），要顯示 `name_zh`。
2. 扇形手牌底部出現橫向捲動 bar（不同意），且 bar 遮住最左邊卡牌。改為：移除捲動 bar、增加卡牌重疊、hover 升高+放大、卡牌置頂於所有介面之上。
3. 選牌卡面：數值為 0 時不顯示；文字縮放至完整顯示；移除右上 `×`（遮住 MP 用量）。

## 根因（已於 codebase 確認）
- `server/game/rules/shopResolver.js:50` 買入 log 用 `shopCard.id`。
- `client/server.js` `serializePlayer`（:46-75）只序列化 `hand` / `selectedCards`，**冇序列化 `discard`**（只有 `discardCount`），故前端 `logView.buildCardNameMap` 掃 `p.discard` 永遠空 → 買入卡 id 唔會被本地化。
- `client/styles.css` `.hand-fan`（:456）用 `overflow-x:auto; overflow-y:hidden` → 底部捲動 bar + hover 升高被縱向裁切。
- `client/views/selectedCardsView.js:43-46` 額外 append 一個 `×` 按鈕，但卡本身 `onClick` 已係點擊移除（:39-42），`×` 屬冗餘並遮住 header 右側 `MP x`。
- `client/layout.js` compact 分支（`cardNode`）對 0 值顯示 `-`，應改為整行唔顯示。

## T1 — 對戰紀錄顯示 name_zh（買入）
- 檔案：`server/game/rules/shopResolver.js`、`client/server.js`（serializePlayer）
- 做法：
  1. `shopResolver.js:50` 買入成功 log 改為 `shopCard.name || shopCard.name_zh || shopCard.id`。`normalizeCard` 已令 `shopCard.name = name_zh`，故輸出即中文名。
  2. `client/server.js` `serializePlayer` 補 `discard: (player.discard || []).map(serializeCard)`，令前端 `buildCardNameMap` 兜底亦可本地化（defense-in-depth）。
- 測試影響：現有測試只檢查 `.includes("購買")`，改字面安全。
- 驗證：`npm run test:rules`（shopResolver / gameEngine）+ 跑一場買入，紀錄顯示「P1 購買 天衡弓箭 成功…」。

## T2 — 扇形手牌：移除捲動 bar + 增加重疊 + hover 置頂
- 檔案：`client/views/handView.js`、`client/styles.css`
- 做法：
  1. `handView.js`：增大 overlap（`overlap = max(26, baseWidth * 0.35)`），令卡牌重疊更多、總寬更細，減少依賴 scale 縮細。
  2. `styles.css` `.hand-fan`：改為 `overflow: visible`（移除 `overflow-x:auto` / `overflow-y:hidden`，即移除底部捲動 bar，hover 唔再被縱向裁切）；保留 `justify-content:center`、`pointer-events:auto`、左右 safe-area padding。
  3. `.hand-fan .card`：負 margin 加大（`margin: 0 -24px`）配合重疊；保留 `transform-origin:center bottom` 與 `transform: rotate(angle) scale(scale)`。
  4. hover：改 `translateY(-18px) scale(1.12)` + `z-index:100`，確保升至所有介面之上（`.hand-panel` 已 z-index:30，卡 hover 在其內部取高位即可）。
- 驗證：`npm run client` 開 Chrome，360/390/414px 核對：無捲動 bar、最左卡牌完整、hover 升高放大唔被裁切、卡牌蓋過棋盤/面板。

## T3 — 選牌卡面：非零數值 + 文字縮放 + 移除 X
- 檔案：`client/views/selectedCardsView.js`、`client/layout.js`、`client/styles.css`
- 做法：
  1. `selectedCardsView.js`：刪除 `removeBtn`（`button("×", …)` append 區塊，:43-46）。卡本身 onClick 已可點擊移除，功能不減。
  2. `layout.js` `cardNode` compact 分支：改為只渲染數值 >0 嘅統計行（`damage` / `blockValue` / `rangeMax` / `moveMax` 大於 0 先出 `ATK/DEF/RNG/MOV`），0 值整行唔顯示。
  3. `styles.css`：
     - 刪除上輪加嘅 `.selected-list .card .mini-button`（X 已移除）。
     - `.card-name` 在 compact 情境容許 wrap 至最多 2 行（`-webkit-line-clamp:2`、`white-space:normal`），令長名完整顯示唔用省略號。
     - `.card-stat` 確保 font 足以完整顯示短文字（`ATK 2` 等），必要時縮細 `font-size`；卡框高度預留空間。
- 驗證：`node --check`（temp `.mjs`）+ Chrome 核對：0 值唔出、長名完整、無 X、MP 用量可見。
