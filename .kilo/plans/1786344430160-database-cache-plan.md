## UI Refine Plan

### 1. Readability
* Increase core gameplay text size to 14px
* Increase card description text size to at least 13px
* Use line breaks in card descriptions

### 2. HUD Information Load
* Reduce number of panels shown during gameplay
* Remove redundant information from player status bar

### 3. Visual Hierarchy
* Make board the primary focus
* Reduce prominence of side panels

### 4. Touch Controls
* Increase size of main buttons to at least 44px
* Make hand fan interactive on mobile devices
* Add safe-area-inset-bottom to hand fan

### 5. Color & Contrast
* Increase contrast between text and background
* Add icons or graphics to card types and tokens
* Limit number of accent colors

### 6. First-Time Experience
* Add tutorial prompt at start of gameplay
* Guide player through first actions

### 7. Retention Risk
* Reduce number of elements on screen
* Simplify gameplay flow

### 8. Google Play Risk
* Reduce text size to prevent clipping
* Ensure sufficient padding around buttons

### 9. Godot UI Review
* Not applicable for web-based projects

### 10. Verification Matrix
* Verify implementation-ready plan with user
* Ensure all important decisions are resolved or explicitly marked out of scope
